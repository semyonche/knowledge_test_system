# QuizCore — система тестирования знаний

Готовый учебный проект на чистом PHP + MySQL.

## Локальный запуск
1. Поместите папку `knowledge_test_system` в `htdocs` (XAMPP) или `domains` (OpenServer).
2. Создайте БД `knowledge_test_system`.
3. Импортируйте:
   - `database/schema.sql`
   - `database/seed.sql`
4. Проверьте настройки БД в `config/db.php`.
5. Откройте `http://localhost/knowledge_test_system/`
